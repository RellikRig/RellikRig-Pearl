# Security reports

Do not post private keys, credentials, or sensitive exploit details in a public
issue. Use GitHub private vulnerability reporting if enabled on this repository.
If that option is unavailable, open an issue requesting a private reporting
channel without including the vulnerability details.

Use the named release assets from this repository. Verify SHA256SUMS before
running the package. Checksums verify file integrity; they are not a separate
publisher signature. Run the miner as a regular user, not as root.
